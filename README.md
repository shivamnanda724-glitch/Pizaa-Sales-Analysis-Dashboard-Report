# 🍕 Pizza Sales Analysis – Power BI Dashboard

## 📊 Project Overview

This project is an interactive **Pizza Sales Analysis Dashboard** created using **Microsoft Power BI**. The dashboard provides insights into pizza sales performance, revenue, order trends, and customer preferences.

The project demonstrates my skills in **Data Cleaning, Power Query, Data Analysis, DAX, and Power BI Data Visualization**.

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Microsoft Excel / CSV
* Data Visualization

## 🧹 Data Cleaning

The dataset was cleaned and transformed using **Power Query**.

Key data preparation steps included:

* Removing unnecessary columns
* Handling missing and incorrect values
* Changing data types
* Creating calculated columns
* Formatting date and time fields
* Preparing the dataset for analysis

## 📈 Dashboard Analysis

The dashboard provides insights into:

* 💰 Total Revenue
* 🧾 Total Orders
* 🍕 Total Pizzas Sold
* 📊 Average Order Value
* 📅 Daily and Monthly Sales Trends
* 🏆 Best-Selling Pizza Categories
* 🍕 Top-Selling Pizzas
* 📦 Sales by Pizza Size
* 📈 Overall Sales Performance

## 🔍 Key Insights

The dashboard helps identify:

* Which pizzas generate the highest sales
* Which pizza categories perform best
* Popular pizza sizes
* Sales trends across different periods
* Overall business performance
